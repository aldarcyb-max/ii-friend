# Сайт врача-стоматолога — инструкция

Обычный статический сайт (HTML/CSS/JS), без сборки и без сервера. Открывается любым браузером.

## Структура файлов

```
index.html       — вся разметка и тексты сайта
css/styles.css   — стили (цвета, шрифты, отступы)
js/script.js     — меню, плавный скролл, карусели
images/          — картинки-заглушки (замените на свои)
```

## Как посмотреть сайт локально

Проще всего — открыть `index.html` двойным кликом в браузере.

Если нужен именно локальный сервер (например, чтобы точно так же вело себя, как на хостинге), а Node.js/Python не установлены, в проекте есть готовый скрипт на PowerShell — запустите из папки проекта:

```powershell
powershell -ExecutionPolicy Bypass -File .claude/serve.ps1
```

и откройте `http://localhost:8933`. Если Node.js или Python всё же есть — подойдёт и `npx serve .`, и `python -m http.server 8000`.

## Как заменить фото на свои

В папке `images/` сейчас лежат заглушки (голубые прямоугольники с подписью). Чтобы поставить реальные фото — **сохраните новый файл под тем же именем** (или поменяйте имя и в `index.html` тоже, в атрибуте `src="images/..."`).

Какой файл за что отвечает:

| Файл | Где используется | Рекомендуемый размер |
|---|---|---|
| `hero-bg.jpg` | Фон главного экрана — уже реальный файл (баннер «Шапка ВК»), не заглушка | 1920×768 — если меняете, держите то же соотношение сторон (2.5:1), иначе картинка обрежется/появятся пустые поля |
| `doctor-portrait.jpg` | Фото врача в разделе «О враче» — уже реальный файл, не заглушка | портрет, соотношение сторон близко к 4:5 |
| `diploma-specialist-pspbgmu.jpg` | Диплом специалиста (ПСПбГМУ) в разделе «Образование» — уже реальный файл | горизонтальный скан диплома |
| `diploma-ordinatura-spbgu.jpg` | Диплом ординатуры (СПбГУ) в разделе «Образование» — уже реальный файл | горизонтальный скан диплома |
| `cert-*.jpg` (10 файлов) | Сетка сертификатов — уже реальные файлы, не заглушки. Чтобы добавить ещё один — положите файл в `images/` и добавьте `<div class="certificate-item">` в `index.html` по образцу соседних | без ограничений — сетка не обрезает картинку, подходит любая ориентация |
Заглушек `portfolio-therapy-*.svg` в проекте больше нет — раздел «Терапевтическое лечение» полностью заполнен настоящими кейсами (см. ниже).

Все фото сжаты до 900–1200 px по ширине (JPEG, качество ~82) — так сайт быстро открывается на телефоне; новые фото лучше сжимать так же. Форматы `.jpg` / `.png` / `.webp` тоже подойдут — главное поменять расширение и в `src`, если оно не `.svg`.

Если фотографий больше или меньше, чем заглушек — скопируйте/удалите соответствующий блок `<div class="certificate-item">…</div>` или `<div class="slide portfolio-slide">…</div>` в `index.html`.

## Как добавить ещё один «Кейс» (разбор случая)

Кейс «все зубы мудрости за один визит» — это **первый слайд** карусели «Хирургическое лечение» (`#surgery-slider`), а не отдельная секция. Для этой карусели он считается одним слайдом/точкой, но внутри у него своя вложенная мини-карусель фото (`case1-*.jpg`) и одно общее описание под ней, которое не меняется при переключении фото — это подчёркивает, что фото сняты в рамках одного случая, а не что это несколько разных случаев. Вместо стрелки — столбик точек справа от фото (`#case1-slider .slider-dots`): навёл курсор на точку — переключилось на нужное фото (на мобильном — просто тап), лишней стрелки на экране нет.

Разметка (`<div class="slide portfolio-slide case-slide">…</div>`): заголовок кейса, `<div class="case-photo-frame">`, затем `<div class="case-description">` с текстом. Фото внутри `case-photo-frame` бывает двух видов:

- **Несколько фото** — вложенная карусель `<div class="slider case-slider" id="caseN-slider">` с точками сбоку (как у Кейса 1 и Кейса 4).
- **Одно фото** (в том числе уже готовый коллаж «до/после» в одной картинке) — просто `<img>` прямо внутри `case-photo-frame`, без вложенной карусели (как у Кейсов 2, 3, 5, 6, 7).

Сейчас в разделе «Хирургическое лечение» 13 таких кейсов (`case1-*` … `case13-*` в `images/`), в разделе «Терапевтическое лечение» — 5 (`therapy-case1-*` … `therapy-case5-*`). Заглушек без реальных фото в обеих каруселях больше нет, показаны только настоящие работы. В «Хирургическом лечении» Кейс 4 стоит первым.

У обеих каруселей верхнего уровня — «Хирургическое лечение» (`#surgery-slider`) и «Терапевтическое лечение» (`#therapy-slider`) — одинаковая навигация: стрелки слева/справа без точек снизу. Точки убраны, потому что кейсы внутри сильно отличаются по высоте (одно фото с короткой подписью vs фото + описание на 5 абзацев или мини-карусель на 6 фото) — единая точка на каждый кейс не спасала бы от прыжков, а резервировать высоту под самый длинный кейс означало бы пустое место под короткими. Стрелки стоят на фиксированной высоте от верха блока (`#surgery-slider .slider-arrow` / `#therapy-slider .slider-arrow { top: 220px; }` в `styles.css`) — не идеально по центру у каждого кейса, зато не скачут и не оставляют пустот.

Чтобы добавить ещё один кейс — скопируйте весь `.case-slide` целиком (тот, что больше похож по формату — с одним фото или с несколькими) как ещё один `<div class="slide portfolio-slide">` в нужной карусели, при вложенной карусели дайте новый `id` (например `case8-slider` или `therapy-case6-slider`) и добавьте атрибут `data-fixed-height` на неё же (иначе точки вложенной мини-карусели «прыгают» при разной высоте фото — см. `script.js`), положите новые фото в `images/` и замените заголовок с описанием.

Если у снимка непривычные пропорции (например, панорамный рентген) и стандартная обрезка `object-fit: cover` срезает края — добавьте картинке класс `case-photo` (как у `case1-*.jpg`), тогда снимок вписывается целиком на тёмной подложке, без обрезки.

Чтобы добавить кейс №2, **не добавляйте его слайдом в существующую карусель** — скопируйте весь блок `case-block` целиком, вставьте следующим (задайте новый `id`, например `id="case1-slider"` → `id="case2-slider"`), положите новые фото в `images/` и замените текст. Так у каждого кейса — своя карусель фото и своё описание, ничего не перепутается и не съедет по высоте.

## Как поменять текст

Весь текст — прямо в `index.html`, в обычных HTML-тегах (`<h1>`, `<p>` и т.д.). Рядом с каждым редактируемым блоком стоит комментарий вида:

```html
<!-- РЕДАКТИРОВАТЬ: заголовок и подзаголовок hero-блока -->
```

Найдите нужный комментарий (Ctrl+F по слову «РЕДАКТИРОВАТЬ»), поменяйте текст между тегами, сохраните файл — готово. Не удаляйте сами теги (`<h1>`, `</h1>` и т.п.), меняйте только текст между ними.

## Как выложить сайт, чтобы он был доступен по ссылке

Самый простой бесплатный вариант — **Netlify Drop**:
1. Откройте https://app.netlify.com/drop
2. Перетащите папку проекта целиком в окно браузера
3. Получите готовую ссылку на сайт

Другой вариант — **GitHub Pages**: залить папку в репозиторий на GitHub и включить Pages в настройках репозитория (Settings → Pages).

## Что можно донастроить

- Ссылки на Telegram/Instagram в разделе перед контактами — сейчас стоят `href="#"`, замените на реальные ссылки на профили (ВК уже настроен).
- Цвета и шрифты — в начале `css/styles.css`, блок `:root` (там же можно поменять радиус скруглений, ширину контента и т.д.).
